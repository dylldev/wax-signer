# Wax already signs and preserves IPAs

The public baseline is **0.16.3, build 108**, compiled for iOS 17 and later. The five libraries separate archive inspection, credentials, signing, installation and sources. The work remaining for 1.0 centers on showing which combinations work on a phone, making failures recoverable and producing the exact normal build through the release pipeline. ## Performance evidence fits one fixture

An earlier private harness reported five samples per mode on one 71,306,992-byte input. Median engine time was 0.958 s using fast deflate and 0.924 s using stored output. Median shelf time was 0.137 s and 0.154 s respectively. The October 30 review recalculated those medians from existing samples. Different timing boundaries and credentials invalidate the earlier cross-product comparison. New corpus, CPU, peak memory, scratch, interruption and phone measurements belong to G5.

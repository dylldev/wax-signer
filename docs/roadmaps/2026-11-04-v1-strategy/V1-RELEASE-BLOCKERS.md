# Resolve defects before qualifying the candidate

Treat B01 as a release-tool defect today. B04 belongs to a draft branch. B06, B08, B09, B10 and B11 ask for missing observations. A missing observation blocks a support claim without establishing a software bug. Severity describes user or release impact. Confidence refers to the stated diagnosis or absence of evidence. Effort is engineering time, excluding device, operator and review waits.

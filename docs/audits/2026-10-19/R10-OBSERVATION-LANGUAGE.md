# R10 milestone — State only observed installation evidence

Baseline R2/main `8ad4b2e`; independent from R3/R8/R12. This fixes concrete outcome-language errors, not all original R10 configuration snapshots/history/retry functionality.

Original `Sources/InstallKit/LoopbackHost.swift:63–68` says “nothing was installed” when delivery is incomplete/not observed. Delivery bookkeeping cannot observe the OS installation decision. `Sources/InstallKit/IdentityStatus.swift:45–55` displays “Installs here” / “installed on this phone” from a certificate-only legacy record. `App/IdentityReadiness.swift:119–125` writes that record after canOpenURL polling; scheme detection does not observe launch, profile/trust correctness, or current configuration. `Sources/InstallKit/SignScreenLogic.swift:81–82` further interprets a negative observation as grounds to hide host setup, and a positive one as eligibility certainty.

Messages now distinguish incomplete delivery, unknown installation outcome, probe detection and unobserved launch. Historical statuses explicitly warn about missing profile/OS context. Legacy enum raw values/Codable/UserDefaults remain compatible, but labels no longer present them as current installation proof. Host setup/retry remains visible and eligibility remains uncertain for either legacy observation. Certificate expiry/pairing/App Store restrictions and cryptographic verification are unchanged.

Tests update unsafe expectations rather than removing checks: negative observation retains setup; legacy positive retains uncertainty; two new status/message regressions; a loopback diagnostic regression prohibits false “nothing installed” claims. Existing IdentityStatus precedence tests still reject expired/invalid pairing. A temporary Linux package compiles the actual Foundation-only IdentityStatus/SignScreenLogic sources and existing/new tests; results recorded after execution. Full macOS/unsigned iOS/simulator CI is required for final-head Apple integration. No device or independent OS install/launch observation is claimed.

Remaining R10: immutable signing-result/configuration binding, richer profile-digest/OS/time observation storage, result retry/change-host/export flows and actual physical observation protocol. R20 nonce/capability probes are separate. This PR deliberately does not reinterpret old records as having unavailable context or invent a successful install. R12 provides source-built probe/tooling; it does not turn URL-scheme availability into launch proof.

# UI polish plan (2026-10-18)

Goal: make every Wax screen clearer, more consistent and more pleasant, without changing the look people already know
(cream and wax-red, floating tab bar, cards, one primary button per screen). Sources: three read-only audits (screens, settings
flows, design system) and the simulator screenshots in light and dark.

## Rules for everyone
- Touch only the files your task owns. Do not commit, do not change git state, do not run `xcodebuild` (the controller builds
  and screenshots after each task). Do not add dependencies.
- Use only the shared components and tokens from Phase 0 (`App/Theme.swift`). If you need a new shared piece, say so in your
  report instead of adding a one-off style.
- Every control keeps a 44 pt target, a VoiceOver label, and works with Reduce Motion. Use `sensoryFeedback`/haptics only on
  meaningful completions. Keep copy short, plain, no jargon.
- Finish by listing what you changed and anything you could not verify (a real iPhone is needed for haptics, keyboard, AX sizes).

## Frozen contract (decided with Codex's critique)
- Phase 0 is finished and **frozen**: nobody but the controller edits `App/Theme.swift` or `App/LocalIPASignerApp.swift` (Router).
  Ask in your report if you need a shared change.
- The shelf contract: Task A sets `router.shelf = .signed` and `router.tab = .ipa`. Task B makes `ContentView` bind its segmented
  control to `router.shelf` (replacing its local `@State`) so that change takes effect.
- Row titles wrap to two lines at large text sizes; they never shrink.
- Keep the existing wax progress animation; stage captions are added next to it, not instead of it.
- No pull-to-refresh on the local IPA shelf (nothing remote to refresh). Sources: pull to refresh means "refresh every source".
- Announce completions to VoiceOver (`AccessibilityNotification.Announcement`) when an import, download, signing or error finishes.
- The pinned save bar uses `safeAreaInset(edge: .bottom)` and must not cover the last field or fight the keyboard.
- The Sources "Get" button reaches a 44 pt target.

## Phase 0 (controller, before the agents): shared pieces in `App/Theme.swift` and `App/Router`
1. Tokens: spacing scale, radii, one standard animation (`Wax.spring`) that respects Reduce Motion.
2. `WaxIconTile(symbol:)`: the rounded tile used in rows; adopt it in `WaxRow`.
3. `WaxEmptyState(symbol or seal, title, message, action?)`: vertically balanced, optional button.
4. `WaxFeedbackCard(tone: .ok/.warn/.bad, text, action?)`: the one banner/error/result card.
5. Button styles get disabled and loading states (spinner), minimum 44 pt.
6. `Router.shelf` (`.unsigned/.signed`) so any screen can send the person to the Signed shelf.

## Task A: Sign flow (agent 1). Owns `App/SignView.swift`, `Sources/InstallKit/SignScreenLogic.swift`
1. One call to action: with no app chosen the big button is the only "Choose an app"; the row becomes a summary
   ("No app chosen" / "Pick an IPA from Files", no trailing link).
2. Errors render above the primary button, as `WaxFeedbackCard`, with a way back ("Choose another file").
3. Result hierarchy: Install (primary), Export (secondary), "Start over" as a quiet text button with an icon; the
   "saved in the IPA tab" line becomes a tappable link that sets `router.tab = .ipa` and `router.shelf = .signed`.
4. Progress shows the stage (Reading, Signing, Uploading) with ticks for finished stages and a 2-line message.
5. Options row becomes a `WaxRow` with a tile. First-run: a three-line checklist (app, identity, install host) when nothing is set up.
6. Haptics: success on signing done, error on failure (light, once).

## Task B: Library and Sources (agent 2). Owns `App/ContentView.swift`, `App/SourcesView.swift`, `App/SourcesModel.swift`
1. Use `WaxEmptyState` for empty shelves and empty sources (balanced, with the next action).
2. Sources "Add" row: `link.badge.plus` tile, a real accent "Add" capsule that is clearly intentional when disabled, and a paste button.
3. Pull to refresh on the Sources list only (refresh every source); `ContentView` binds to `router.shelf`; row titles wrap at large text sizes.
4. Light haptic on Get; success haptic when a download finishes.

## Task C: Settings and credentials (agent 3). Owns `App/SettingsView.swift`, `App/CredentialsView.swift`, `App/SigningOptionsView.swift`, `App/InstallSection.swift`, `App/DocumentPicker.swift`
1. Signing options: pinned bottom "Save as defaults" bar that is disabled until something changed, then shows "Saved" with a check.
2. Credentials: import success becomes a quiet `WaxFeedbackCard(.ok)` with a scroll to the new card and a success haptic; errors stay prominent.
   Busy state uses the existing `WaxProgressBar` beside the live message instead of a bare spinner.
3. Install host fields keep a visible label after they are filled; keyboard dismisses on scroll; "Forget token/keys" asks first and says what is lost.
4. Status line shows a spinner while checking and an ok/bad pill with icon afterwards.
5. Smaller fixes: icon thumbnail after choosing an icon, "Delete 3 apps (1.2 GB)?" wording, VoiceOver labels and 44 pt targets on the trash buttons,
   import-log Refresh in the toolbar with Clear confirmed, a link to the repository in About.

## Review loop
Controller builds and screenshots (light, dark, large text, iPhone SE width) after each task; Codex and the controller review the
diff; findings go back to the agent; repeat until the controller and Codex agree. Release stays blocked on the phone test.
